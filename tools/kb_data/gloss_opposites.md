# gloss_opposites.json の由来（監査メモ）

`snipher/data/gloss_opposites.json` は **語義（英語グロス）どうしの対義対応表** です。

## なぜ必要か

「〜の対義語は？」という問いに、Snipher は *その場で確かめられる材料* だけで答えます。
その材料になるのが、実データに入っている語義です。

```
snipher/data/adjectives.json   {"s": "嬉しい", "g": "happy"} / {"s": "悲しい", "g": "sad"}
snipher/data/verbs.json        {"s": "増える", "g": "increase"} / {"s": "減る", "g": "decrease"}
```

語そのものの対応（嬉しい → 悲しい）をデータに書くと、それは「答えの暗記」になります。
ここに置くのは **グロスの対** だけです。実際の答えは 2 段の計算で引きます。

1. 問われた語（嬉しい）の語義を実データから引く → `happy`
2. 対義の語義（`sad`）を持つ語を実データから探す → 悲しい

だから、対応表に無い語義の語は「対義語を出せない」と正直に返ります（捏造しない）。

## 作り方（規則）

- `adjectives.json` / `verbs.json` の `g` 欄に **実在する語義文字列** だけを対にする。
- 意味の核が反転する組だけ。程度の差（高い/低い、暑い/寒い）は「対義」ではなく段階なので、
  天候の寒暖のように語自体が対で使われる組だけを載せる。
- 語義が 2 つ以上ある語（`beautiful/clean` のような併記）は、核の語義だけで判定する。
- 追加・変更はこのファイルと JSON の両方に理由を書く（後から検算できるように）。

## 由来

- 語義グロス: Janome / IPADIC 由来の語彙を `tools/build_lexicon.py` で
  `snipher/data/adjectives.json`・`verbs.json` に書き出したときの英語語義。
- 対の選定: 日本語話者による人手（このリポジトリの整備）。辞書そのものの転載ではありません。
